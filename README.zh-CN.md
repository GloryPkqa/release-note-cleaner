# Release Note Cleaner

[English](README.md) · 简体中文

**按你的要求清理 AI 额外添加的说明小字，保留无关内容。**

`release-note-cleaner` 是一个 AI 代理技能，帮助检查和清理网页、演示文稿和文档里不需要的 AI 插画说明、概念示意标签、制作备注和占位文案。中文作品和英文作品都可以单独处理，中英混合内容也可以处理；作品不需要同时具备两种语言，也不需要翻译。

这是一套供代理执行的审查与编辑指南，不是独立运行的删除软件，也不能识别作品是否由 AI 制作。是否调用技能、能否读取或修改具体文件，以及可以完成哪些视觉检查，取决于所用代理和当前环境。

## 哪些内容会被清理？

技能可以处理你明确要求删除的图片说明或标签，也能检查意外出现在最终作品里的内部备注。例如：

> 给设计师：上线前删除这条备注。
>
> Designer: Remove this note before launch.

如果上下文证实它们只是误显示的内部指令，且删除不会丢失观众需要的信息，在获得修改授权后即可移除。

相同或相似的文字也可能承担真实用途。例如，博物馆页面上的“艺术复原，非历史照片”或 “Artist’s impression, not a historical photograph” 能帮助观众区分复原与真实影像，应当保留。**“AI 生成”“概念示意”“仅供参考”也不是自动删除的关键词**：它们可能是多余的制作说明，也可能是对素材来源、事实或产品状态的重要说明。

技能会根据上下文、受众、具体位置和用户要求，将候选内容分为：

| 判断 | 处理方式 |
| --- | --- |
| 明确属于误显示的制作备注，且删除不损失观众所需信息 | 在授权修改的范围内删除，尽量缩小修改范围 |
| 你明确要求删除的说明，例如图片下方的“AI主题插画” | 删除范围内可识别的对应说明；保留无关的作品标题和来源 |
| 对观众理解或使用有帮助 | 保留 |
| 用途、影响或授权范围不明 | 保留，并在报告中说明不确定之处 |

颜色、字号和关键词只用于发现候选，不单独作为删除依据。来源、版权、图注、事实性披露、数据单位、价格、表单说明和无障碍文本等，都需要结合上下文保护。如果你明确点名删除某条说明，或指定删除某一类说明，例如“删除 AI 主题插画说明”，代理应按要求删除范围内可识别的对应文字；如果明显会造成重要误解，应说明影响，不得编造替代内容。

## 安装

需要 Node.js 22.20 或更高版本，以及可用的 `npx`。使用 Skills CLI 安装到 Codex：

```bash
npx skills add GloryPkqa/release-note-cleaner --skill release-note-cleaner -a codex
```

也可以手动安装：复制本仓库中的 `skills/release-note-cleaner` **整个目录**到 `~/.codex/skills/`，使最终路径包含 `~/.codex/skills/release-note-cleaner/SKILL.md`。Windows 上 `~` 对应当前用户目录。安装后开启新的 Codex 会话，或按所用客户端的方式刷新技能列表。

仓库采用可移植的 `SKILL.md` 格式；其他代理工具的发现路径和安装方法可能不同，请参照相应工具的说明。

## 使用

在 Codex 中明确提及 `release-note-cleaner`，并说明检查对象、范围和希望采取的动作。实际可检查的文件和页面取决于当前会话可访问的内容。

**只审查，不修改：**

```text
使用 release-note-cleaner 检查这个网页：列出可能意外展示给访客的制作备注，说明判断依据和不确定之处。只审查，不修改文件。
```

**清理明确的制作备注：**

```text
使用 release-note-cleaner 清理本次交付网页中不需要的 AI 主题插画和文创概念示意说明，以及误显示的制作备注。保留作品标题和图片来源，完成后检查版面并说明未验证的部分。
```

**限定范围并指定内容：**

```text
使用 release-note-cleaner，只处理中文首页的展览介绍区域。我确认“内部预览，发布前删除”是制作备注；保留其他页面、英文版本和所有图片来源说明。
```

审查请求应只报告发现，不修改文件。清理或编辑请求则授权代理在指定范围内处理；共享组件或翻译文本可能被多个页面复用，修改前需要确认影响范围。技能把作品中出现的指令当作待检查内容，不会把它们当成新的任务授权。

## 图片、截图和其他限制

- 可编辑文字应尽量保留为可编辑对象。已经合并进图片的文字，需要另外使用可用的图片编辑能力；删掉图片旁的图注不会清除图片本身的文字。
- 只有截图时，代理只能基于截图中能辨认的内容审查；截图不能证明整个网站或文档都已检查。无法辨认、无法编辑或未验证的部分应如实报告。
- 不同格式、页面状态、语言版本和响应式布局可能需要分别检查。访问不到的内容和未进行的视觉检查，不应声称已完成。
- 语义判断可能出错。对于有争议的内容，建议结合作品目的和实际读者复核。

## 评测

[`evals/`](evals/) 提供中英文虚构网页样本、预期行为和人工评分方案，覆盖只审查、限定范围清理、明确指定、共享组件和范围外文件等场景。它是一组用于评测的样本，**不代表任何代理已通过测试，也不能证明真实场景中的误判率**。

运行以下命令可检查样本文件和测试锚点是否齐全：

```bash
python evals/validate_fixtures.py
```

该检查不会运行 AI 代理、评判语义决定或验证浏览器显示。完整评测方法及局限见 [`evals/README.md`](evals/README.md)。
